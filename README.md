# Michael's Kitchen 🍲

A lightweight, interactive web application for a local restaurant menu that lets customers place food orders directly via WhatsApp.

---

## 🔗 Live Demo
Check out the live website here:  
👉 [Michael's Kitchen Live Site](https://michael-kitchen-dev.github.io/michael-kitchen/)

---

## ✨ Features
* **Interactive Menu:** Browse available food items and prices.
* **Order Customization:** Input customer name, quantity, and special notes/instructions.
* **Direct WhatsApp Integration:** Formats the order details automatically and redirects to WhatsApp for quick checkout.

---

## 🛠️ Built With
* **HTML5** - Page structure and menu layout
* **JavaScript** - Form validation and WhatsApp link generation
